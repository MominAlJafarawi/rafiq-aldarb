# رفيق الدرب

برنامج لتعلّم الألماني من A1 لـB2 للناطقين بالعربي، لماك وويندوز. تطوير: **مؤمن الجعفراوي**.

## ⬇️ التنزيل

**[آخر نسخة من صفحة التنزيل](https://github.com/MominAlJafarawi/rafiq-aldarb/releases/latest)**

| الجهاز | الملف |
|---|---|
| ماك (Apple Silicon، macOS 14 أو أحدث) | `RafiqAlDarb-Mac.zip` |
| ويندوز (تثبيت) | `RafiqAlDarb-Setup.exe` |
| ويندوز (بدون تثبيت) | `RafiqAlDarb-Windows-x64.zip` |
| الصوت الألماني الطبيعي (اختياري) | `RafiqAlDarb-Voice-Mac.rafiqpack` / `RafiqAlDarb-Voice-Win.rafiqpack` |

البرنامج بيشتغل بكود تفعيل من المطوّر لكل جهاز. أول ما تفتحه بيطلعلك رقم جهازك: ابعته للمطوّر، وبيبعتلك الكود.
